Архитектура данных — как вносить правки

Вся карта описана в начале <script>, секция «1. ДАННЫЕ». Четыре массива/объекта: META, PALETTE, LEVELS, NODES, EDGES. Разметка и алгоритмы данных не содержат.

Уровень обязательности — LEVELS

const LEVELS = {
  // ключ: { label — подпись, color — цвет рамки и маркера }
  must:  { label:'Обязательно', color:'#ef4444' },
  core:  { label:'Важно',       color:'#f59e0b' },
  extra: { label:'По желанию',  color:'#64748b' },
};
// Добавьте свой уровень — он появится в легенде автоматически.
// У подтемы: level:'must'  (если не указан — DEFAULT_LEVEL)

Узел (тема) — NODES

{
  id:      'foundation',   // уникальный ключ, латиница
  title:   'Фундамент',
  kind:    'topic',        // milestone | topic | hub
  row:     1,              // ряд сверху вниз (0, 1, 2 …)
  color:   'amber',        // ключ из PALETTE
  width:   200,            // px, необязательно

  // куда раскладывать подтемы относительно карточки:
  leavesSide: 'left',      // 'left' | 'right' | 'split' (половина слева, половина справа)
  leafWidth:  180,         // ширина карточки подтемы

  summary: 'Короткий подзаголовок под названием',
  desc:    'Подробное описание для боковой панели. **жирный**, `код`',

  items: [ /* подтемы — см. ниже */ ]
}

Подтема — элемент items[]

// Короткая форма:
'Схемотехника'

// Полная форма:
{
  title: 'ТАУ и ПИД',
  level: 'must',          // ключ из LEVELS → цвет рамки
  side:  'left',          // необязательно: принудительная сторона при leavesSide:'split'
  desc:  'Что именно изучить…',
  links: [ { label:'Wikipedia', url:'https://…' } ],
  id:    'pid'            // необязательно: зафиксирует ключ прогресса
}

Связи — EDGES

{ from:'start', to:'foundation' }                              // сплошная, ортогональная
{ from:'docs', to:'standards', kind:'skip', side:'right' }       // пунктир в обход по внешней шине

Связи «тема → подтема» рисуются автоматически (пунктир), их описывать не нужно.

Плотность раскладки — CFG

CFG.cardWidth   // ширина карточки темы по умолчанию
CFG.leafWidth   // ширина карточки подтемы по умолчанию
CFG.leafGap     // зазор между темой и колонкой подтем
CFG.colGap      // зазор между блоками в одном ряду
CFG.rowGap      // зазор между рядами (там идёт общая шина)
CFG.vGap        // зазор между подтемами в колонке
CFG.corner      // радиус скругления углов у линий
STORAGE_KEY     // смените при несовместимом изменении схемы
